# Pantry Recipe App

A modern web application for managing your pantry and discovering recipes, powered by Supabase.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Set Up Supabase Connection

1. Create a `.env` file in the root directory
2. Add your Supabase credentials:
   ```
   VITE_SUPABASE_URL=your_project_url
   VITE_SUPABASE_ANON_KEY=your_anon_key
   ```
3. See `SETUP.md` for detailed instructions

### Run Development Server
```bash
npm run dev
```

The app will be available at `https://localhost:3443`

### Build for Production
```bash
npm run build
```

## Features

- 📦 Pantry management with Supabase backend
- 🍳 Recipe management with Supabase backend
- 💾 Automatic data sync with your Supabase database
- 🎨 Modern, responsive UI
- 🔄 Real-time data updates
