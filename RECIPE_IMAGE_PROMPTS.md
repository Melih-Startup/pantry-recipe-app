## PROMPT SETTINGS CHEAT SHEET (for Nano Banana)

| Setting | Recommended Value |
|---------|-------------------|
| **Aspect Ratio** | 16:9 |
| **Resolution** | 2K (2560x1440) |
| **Style** | Photorealistic / Editorial |
| **Quality** | Ultra / Maximum |
| **Guidance/CFG** | 7-9 (balanced creativity + fidelity) |
| **Steps** | 30-50 (higher = more detail) |
| **Sampler** | DPM++ 2M Karras or Euler a |
| **Negative Prompt** | text, watermark, logo, blurry, low quality, distorted, cartoon, illustration, overexposed, underexposed, oversaturated, artifacts, noise, grain, cropped, out of frame, ugly, deformed |
